# ankacha.github.io

Landing page for a small family of self-contained, browser-based structural engineering learning tools. Each tool is a single HTML file — nothing to install, nothing to sign in to, and it runs offline on a laptop, tablet or phone.

**Live site:** https://ankacha.github.io

## Projects

| Project | What it does | Path |
|---|---|---|
| **Frame Pusher** | Interactive 2D frame finite-element analysis: nodes, members, steel sections, supports, loads and end releases, with bending moment, shear and deflection diagrams and a live stiffness-matrix view. | [`/frame-pusher`](https://ankacha.github.io/frame-pusher/) |
| **Arch Pusher** | Lower-bound thrust-line analysis of masonry arches, vaults and domes, including multi-ring brick arches, bonding and ring separation. | [`/arch-pusher`](https://ankacha.github.io/arch-pusher/) |
| **Cable Pusher** | Cable and tension structures from first principles: catenary shape, sag, horizontal thrust and cable tension under point and distributed loads. | [`/cable-pusher`](https://ankacha.github.io/cable-pusher/) |
| **Plate Pusher** | Bending of flat plates and slabs: shape, thickness and edge supports, pressure and patch loads, with deflection and moment contours. | [`/plate-pusher`](https://ankacha.github.io/plate-pusher/) |
| **Lintel Loader** | Loads on lintels over openings in masonry walls: load triangles, arching action and point loads, with the resulting moment, shear and end bearing. | [`/lintel-loader`](https://ankacha.github.io/lintel-loader/) |
| **Codex Structura** | Timeline and lineage explorer for historic British structural standards and codes of practice, to support appraisal of existing structures. | [`/codex-structura`](https://ankacha.github.io/codex-structura/) |

## Repository layout

```
ankacha.github.io/
├── index.html              ← this landing page
├── README.md
├── frame-pusher/index.html
├── arch-pusher/index.html
├── cable-pusher/index.html
├── plate-pusher/index.html
├── lintel-loader/index.html
└── codex-structura/index.html
```

Each app lives in its own folder as `index.html`, so it is served at `ankacha.github.io/<folder>/`. The landing page links to those folders with relative paths (`frame-pusher/`, `plate-pusher/`, …), so the site also works when opened locally.

## Running locally

Open `index.html` directly in a browser, or serve the folder to mimic GitHub Pages:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Publishing

1. Push to the `main` branch of the `ankacha.github.io` repository.
2. In **Settings → Pages**, set the source to *Deploy from a branch*, branch `main`, folder `/ (root)`.
3. The site is published at https://ankacha.github.io after a minute or two.

## Adding a new project

1. Create a folder named after the project (lower-case, hyphenated) and put the app in it as `index.html`.
2. In the landing page `index.html`:
   - add a link to the `<nav>` in the top bar;
   - copy an existing `<a class="card">` block, then update its href, tag, SVG artwork, title, description and URL line;
   - if the artwork is generated by script, add a block for it in the `<script>` at the bottom;
   - update the `<meta name="description">`, and bump the version in the `<title>`, top bar and footer.
3. Add a row to the **Projects** table above and an entry to the changelog below.

## Theme

The page shares the cyberpunk look of the Frame Pusher family: dark by default with a light theme toggle (remembered per browser), purple / magenta / cyan accents, and animated SVG card art that respects `prefers-reduced-motion`.
